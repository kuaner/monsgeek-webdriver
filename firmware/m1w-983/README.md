# M1W 983 原厂固件 1.08

这里保存容圆 M1W（设备 ID `983`，有线 USB `3151:4015`）的原厂 1.08 固件，以及独立的 macOS 升级脚本。**只适用于设备 983 从 1.04 升级到 1.08**，不适用于 M1W VIA、M1W 的其他设备 ID 或 M7W。

## 固件文件

| 文件 | 内容 | SHA-256 |
| --- | --- | --- |
| `983_v108.deflate` | 原厂服务器返回的原始压缩包 | `99e93a620c60745bff1e01d69a75055d2e25a3cfcfc87561db7d3c0edfb4b4a6` |
| `983_v108.bin` | 解压后的原厂固件镜像 | `7c8f0287d2d4dc916f88e68ad59e56544187faa8c5c008441a068d1922aa26c7` |

固件来自容圆的 `get_fw_version` 接口及其返回的 `fw_upgrade_file/983_v108` 下载路径；服务器返回的版本信息保存在 [metadata.json](metadata.json)。固件为原厂二进制文件，不属于本项目编写的代码。

我们曾用该镜像将一把设备 983 从 1.04 升级到 1.08，收到 bootloader 成功应答，并在重连后验证了设备 ID 和版本。发布版脚本基于当时的刷写逻辑整理，增加了模拟测试；整理后的版本没有再次对实体键盘刷写。

## 使用

需要 macOS、Python 3 和 libusb。可通过 Homebrew 安装 libusb：

```sh
brew install libusb
```

用数据线连接键盘并切换到有线模式，关闭其他正在连接键盘的驱动和浏览器页面。在仓库根目录先运行只读检查：

```sh
python3 firmware/m1w-983/m1w_flash983.py
```

确认输出的设备 ID 是 `983`、当前版本是 `0104`、板载配置档 `profile` 是 `0` 后，使用一个**尚不存在**的目录记录升级过程：

```sh
python3 firmware/m1w-983/m1w_flash983.py \
  --flash-official-v108 --session-dir ~/m1w-update-983-v108
```

脚本会校验压缩包、解压结果和设备身份，等待同一 USB 端口上的 bootloader（`3151:4016`，版本 `0729`），传输镜像后校验应答，并等待键盘恢复到 1.08。它不会自动导出键盘配置；如需保留配置，可在升级前通过网页手动保存。升级过程中请保持 USB 连接。

会话目录只记录设备身份、端口及传输进度，不包含按键、宏或灯光配置。如果中途失败，不要删除该目录；只有开始传输头尚未发送时，脚本才允许使用 `--resume-session ~/m1w-update-983-v108` 继续，其他情况会拒绝自动重试。**进入 bootloader 或中断刷写可能导致键盘暂时无法使用，目前没有经过验证的通用救援方法。**

当前固件已是 1.08 时脚本会退出，不支持强制重刷、降级、任意固件或 WebHID 刷机。

## 测试

```sh
python3 -m unittest discover -s firmware/m1w-983 -p 'test_*.py' -v
```

测试使用模拟 USB 设备，不会向键盘发送命令。
